# 기획안: 엔저 일본 골프채 가격 비교 (golfprice.unclepony.com 새 섹션)

- 작성 2026-10-18 · 상태: **사장님 승인 대기 (아직 아무것도 만들지 않음)**
- 근거: 아이디어 조사 1순위(ops 보고 #68) — 원/엔 100엔당 842원(2026-10-07, 약 18년 만의 최저 수준), 2026년 1~8월 한국인 방일 742만 명(+21%)

## 1. 한 줄 요약
일본 내수용·일본 전용 골프채의 **일본 제조사 정가 vs 한국 정가**, 그리고 **직구 총비용(물건값+배송+세금)**을 한 화면에 보여 주는 새 섹션. 국내 A/S 불가 경고를 반드시 함께 표시.

## 2. 검색 수요 (확인한 것만)
네이버 데이터랩 검색어트렌드, 2025-10-18 ~ 2026-10-18 일별, 전체 기기·성별·연령. 사장님이 2026-10-19 직접 조회한 캡처([datalab-japan-club-2026-10-19.png](datalab-japan-club-2026-10-19.png))를 눈으로 읽은 값입니다. 데이터랩 값은 기간 안 최고 검색량을 100으로 둔 **상대값**이라 실제 검색 횟수는 알 수 없습니다.

| 검색어 | 그래프에서 읽은 모습 |
|---|---|
| 일본 골프채 | 대부분 **25~50**을 오감. 최고 100은 2025년 10월 말~11월 초에 한 번. 최근(10월) 약 57까지 오름 |
| 일본 골프채 직구 | 0~29, **0인 날이 많음** = 하루 검색량 자체가 적음. 8월 이후 위쪽 봉우리(20~29)가 조금 잦아짐 |
| 일본 골프채 가격 | 거의 0 (두 번 잠깐 약 7) |
| 일본 내수용 드라이버 | 그래프에 거의 보이지 않음(0에 가까움) |
| 젝시오 일본 | 1년 내내 0 |

**해석**
- 수요는 '크지 않지만 꾸준한' 수준. 사람들은 '내수용·가격' 같은 긴 말보다 **'일본 골프채'** 라는 짧은 말로 찾음 → `/jp/` 첫 화면의 제목과 설명은 '일본 골프채'를 중심 키워드로, '직구'를 보조로.
- 엔저 때문에 검색이 뚜렷하게 늘었다는 증거는 이 그래프에 **없음**(직구 쪽이 8월 이후 조금 늘어난 정도).
- 실제 월 검색 횟수(절대값)는 네이버 검색광고 키워드 도구가 있어야 앎(광고 계정 필요, 지금은 안 함).
- 데이터랩 API 는 2026년부터 네이버클라우드 NAVER API HUB 로 옮겨져 요금 확인 전이라 쓰지 않음. 이 작업 환경에서는 datalab.naver.com 이 열리지 않아 사장님이 직접 조회해 주셔야 함.
- 우리 서치콘솔 검색어 중 '일본·직구·내수·엔저'는 0건. 관련 페이지가 아직 없으니 당연한 결과임.

→ **제안: 작게 시작**. `/jp/` 첫 화면 1장 + 모델 5장 + 직구 안내 1장으로 시작하고, 3개월 뒤(2027-01 말) 서치콘솔 노출·클릭으로 확장할지 중단할지 판단.

**조사에서 나온 중요한 사실 (기획 방향에 영향)**
- 5개 모두 **한국에서도 정식 판매**되는 모델이었음. '일본 한정' 후보였던 혼마 BERES JP그레이드는 공식 정가를 찾지 못해 뺐음(판매점 가격만 보여서 안 씀).
- 정가 차이는 1.5%~28%. 하지만 직구하면 관세·부가세·배송비가 더해져 **차이가 크게 줄거나 뒤집힐 수 있음** → 페이지의 핵심 메시지는 "엔저라도 무조건 싸지 않다, 총비용으로 보자"(정직한 비교가 신뢰·체류 시간에 유리).
- 한국 공식몰 '판매가'는 소비자가보다 낮음(예: XXIO 14 980,000원, ZXi RKT 850,000원, JPX ONE 690,000원). 비교는 정가끼리, 판매가는 참고로만.
- 섹션 범위를 '일본 내수 전용'에서 **'일본 정가 vs 한국 정가(같은 모델) + 일본 한정 모델(정가 확인되는 것만)'**으로 넓히는 것을 제안.

- 일본 가격은 제조사 공시 '희망소매가격'(세금 포함 표기 기준). 실제 일본 판매가는 정가보다 낮은 경우가 많지만 **라쿠텐 등 판매가는 쓰지 않음**(라쿠텐 약관상 쿠팡 링크 옆 노출 불가). 쿠팡 페이지도 열지 않음.
- 환산은 원/엔 공시 환율(한국수출입은행 매매기준율 등 공식 출처)을 날짜와 함께 표시. 지어낸 숫자 0.

## 4. 직구 총비용 계산 방식
`총비용 = 일본 구매가(정가 기준, 사용자가 실제 가격으로 바꿔 넣을 수 있음) + 일본 내 배송·배대지 비용 + 국제 배송 + 관세·부가세`
- 비교 대상: 한국 정가, 그리고 기존 사이트가 이미 보여 주는 쿠팡 판매가(`prices.csv` 수동 확인값·확인일, 있는 모델만). 일본 사양을 들여온 병행수입품이 쿠팡에 있으면 그 링크도 연결 후보.
- 세금은 **우리가 계산하지 않고 관세청 공식 안내로 연결**:
  - [관세청 해외직구물품 예상세액 조회](https://www.customs.go.kr/kcs/ad/tax/BuyTaxCalculation.do)
  - [관세청 소액면세제도 FAQ](https://www.customs.go.kr/call/ad/crmcc/selectFaqViewPage.do?mi=6822&cnslKnwlSrno=512) · [목록통관 FAQ](https://www.customs.go.kr/call/ad/crmcc/selectFaqViewPage.do?mi=6822&cnslKnwlSrno=463) · [특송물품 통관](https://www.customs.go.kr/kcs/cm/cntnts/cntntsView.do?mi=2821&cntntsId=819)
- 관세청 안내 요지만 인용: 면세 기준은 물품가격 미화 150달러(미국발 200달러) 이하, 넘으면 운임·보험료 포함 과세. 드라이버는 대부분 이 기준을 넘으므로 "세금이 붙는 것이 기본"이라고 씀.
- 통관 회피 요령(분할·저가 신고 등)은 **절대 쓰지 않음**. 배송비는 업체·무게마다 달라 '입력칸'으로 두고 고정 숫자를 넣지 않음.
- 여행 중 현지 구매는 [관세청 여행자 휴대품 면세 안내] 링크로만 안내(구현 시 공식 URL 확인).

## 6. 페이지 구성·URL (새 주소만, 기존 페이지·문구·URL 손대지 않음)
| 새 URL | 내용 |
|---|---|
| `/jp/` | 섹션 첫 화면: 오늘 환율, 정가차 큰 순 모델 표, 직구 총비용 계산기(관세청 링크), 경고 |
| `/jp/{모델-slug}.html` | 모델별: 일본 정가·한국 정가·차액(%), 사양 차이, A/S 경고, 국내 정식품 쿠팡 링크(기존 링크가 있는 모델만) |
| `/jp/weekly/{YYYY-WW}.html` | '이번 주 가격차 큰 모델' 주간 글 |
| `/jp/guide-customs.html` | 직구·세금 안내(관세청 링크 모음, 회피 요령 없음) |

- 기존 `/c/`, `/g/`, `/p/` 페이지 문구는 그대로. 연결은 사이트 메뉴·사이트맵에 항목 추가만(사장님 승인 시).
- 사진·로고 없음(텍스트 표·도식만). build.mjs 의 URL 보호·사이트맵·IndexNow 를 그대로 탐.
- 수익: 국내 정식품이 오히려 싸거나 A/S 가 필요한 사람에게 기존 쿠팡 파트너스 링크로 연결(대가성 고지 기존 문구 재사용).

## 7. 데이터 갱신 계획
- 데이터 파일: `config/jp-models.json`(모델·일본/한국 정가·출처 URL·확인일). 정가는 출시·개정 때만 바뀌므로 **월 1회 수동 확인**, 제조사 페이지 자동 크롤링 안 함.
- 환율: 공식 환율 API(한국수출입은행 Open API, 키 필요 시 사장님께 요청) 매일 1회 → 차액만 다시 계산.
- 주간 시리즈 **'이번 주 가격차 큰 모델' TOP 5**(월요일): weekly.yml 에 이어서 `/jp/weekly/` 글 생성 → 같은 데이터로
  - ATL골프기어 쇼츠 대본(숫자·출처·확인일 자막, 쿠팡 언급 없음 — 기존 영상 원칙)
  - 인스타그램 카드 문구(텍스트·도표만, 제품 사진 없음)
  를 golfvideo 쪽이 읽는 JSON 으로 내보냄. 쇼츠를 '영상마다 다른 숫자' 형식으로 바꾸는 첫 시리즈(보고 #68).
- 신제품 소식은 제조사 보도자료의 사실만. 제조사 사이트에서 정가를 옮길 때 그 사이트 이용 조건을 지킴(자동 수집 안 함).
- 나중 확장 후보(승인 별도): '엔저 골프 리포트' — 클럽 가격차 + 일본 골프여행 공개 패키지가(출처·날짜 인용) + 원/엔 흐름.

## 8. 셀프 개선 고리
1. 목적: 일본 직구 관심 검색 유입 → 국내 정식품 쿠팡 클릭.
2. 매일: /admin 의 /jp/ 페이지뷰·유입 경로·쿠팡 클릭률, 서치콘솔 /jp/ 노출·검색어.
3. 데이터 보강: 검색어에 나오는데 표에 없는 모델은 다음 달 추가 후보로 기록.
4. 분석: 노출은 되는데 클릭이 없는 페이지는 title/description 원인 분석(기존 주간 분석 방식).
5. 적용: 확실한 것은 바로, 불확실한 것은 실험·판단일 기록(reports/experiments.md). 변경 하나=커밋 하나.
6. 보고: ops.unclepony.com.

## 10. 승인 요청
1. 수요가 작지만 꾸준하므로(2장) '작게 시작 → 3개월 뒤 판단'으로 진행할지 여부
2. `/jp/` 새 섹션 URL 구조 승인
3. 주간 '가격차 큰 모델' 시리즈를 ATL골프기어 쇼츠·인스타에 재사용 승인
